# 1.1.0

## Updates:
- 新增「界面风格（UI 体系）」设置项，可在 Miuix / Material 3 Expressive / 麻薯 Mochi 之间切换
- 新增 `ZhiPageSet` 页面组契约，每个页面带 `@Composable` 默认实现回落到 Miuix，新增风格只需覆写想改的页面
- 新增 Material 3 Expressive 界面风格，覆盖全部 17 个页面
- 新增麻薯 Mochi 界面风格，覆盖关于 / 更新 / 隐私 3 个页面
- 新增「液态玻璃」材质开关，仅在麻薯风格下可用
- 新增帧耗时与重组计数探针的构建开关，正式包可通过 `-PframeTrace=true` 启用
- 新增侧栏工作区聚合，会话按工作区归并
- 新增内置 Node 与 Pi 运行时
- 新增 Pi 多供应商预设图标

## Changes:
- 启用 Compose 强跳过（`enableStrongSkippingMode`），状态未变时整页跳过重组
- 云端镜像切换至 Ubuntu 24.04
- 模型名改为滚动显示，API 配置弹窗改为本地双级
- 上下文窗口支持小数显示
- 「界面风格」以页面组 id 字符串落盘，读取失败时回落到默认组

## Fixes:
- 修复上滑加载历史后对话流跳到顶部
- 修复打开设置页后对话流被顶到底部
- 修复顶栏与底部导航栏的背景模糊丢失
- 修复页面切换过程中模糊块变为半透明再恢复的问题
- 修复移除导航栈后转场期间同时组合上下两页造成的开销
- 修复 Pi 重启后丢失上下文
- 修复无 API 配置时保存越界
- 修复首次启动引导流程
- 修复终端 groups 告警
- 修复 Pi 真机工具调用未经校验

## Refactors:
- 移除麻薯导航栈，回到 Miuix 自身的 `NavDisplay` 页面栈
- 移除转场期间的背景捕获暂停机制
- 将 33 个页面文件移入 `pages/miuix/` 子包
- 重构上下文压缩的恢复逻辑
- 重构 Pi 多供应商预设
